RaillRunner เกมอาร์เคด 3 มิติสุดมันส์ เล่นได้ไม่รู้จบ ขับเคลื่อนด้วยรางรถไฟ ได้แรงบันดาลใจจากเกมมือถือคลาสสิกอย่าง Subway Surfers หลบหลีกรถไฟที่วิ่งเข้ามา กระโดดข้ามรั้วกั้นรางรถไฟ ลอดใต้สัญญาณไฟ และเก็บเหรียญไปพร้อมๆ กับการหลบหนีการรักษาความปลอดภัยบนรางรถไฟ

คุณสมบัติ การสร้างสนามแข่งแบบไดนามิก: สนามแข่ง 3 เลนที่สร้างขึ้นโดยอัตโนมัติ มีอุปสรรคสูง และสิ่งกีดขวางข้างทาง การเคลื่อนไหวที่ลื่นไหล ออกแบบมาเพื่อการหลบหลีก และการกระโดดที่รวดเร็ว พลังพิเศษและไอเทมเก็บสะสม: แม่เหล็กดูดเหรียญ: ดูดเหรียญที่อยู่ใกล้เคียงโดยอัตโนมัติในทั้งสามเลน รวบรวมเหรียญพื่อปลดล็อกนักวิ่งที่ไม่เหมือนใคร และชุดต่างๆ การติดตามคะแนนสูงสุด: การควบคุม แป้นพิมพ์ (พีซี) การเล่นปุ่มเคลื่อนที่ ซ้าย A/ ขวา D กระโดด spacebar)
